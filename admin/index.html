How to use Easy Mandi admin

1. Update your catalog

  1. Review store settings, delivery fees and minimum order.
  2. Add a category before assigning products to it. Rename updates the products in that category. Move its products before deleting a category.
  3. Search, filter or sort the product grid. Choose Add product, Update or Delete to open the record form. Insert and Update validate the fields before changing your draft.
  4. Choose Validate catalog, then Save to server. Sign in through the password pop-up if your 30-minute session has ended. Changes become available when customers reload the catalog.

2. Manage customer orders

  1. Sign in using the password pop-up, then go to Customer orders.
  2. Filter by status, review items, totals, address and map pin.
  3. Choose a status and Update status. Refresh orders to see recent changes.
  4. Choose Open in delivery admin on an order to carry its ID into the import form. Sign in there and choose Import order.

3. Drafts and backups

Edits are saved as a draft in this browser. Save to server publishes them. Download backup saves a JSON copy without publishing.

Reload published catalog discards your draft after confirmation. If saving reports a changed server version, review the latest catalog before retrying.

Choose Lock after reviewing orders on a shared device.

Notifications: While signed in, updates refresh every five minutes. New updates appear automatically without clicking Refresh or re-entering a password. Unread entries are highlighted. Use Mark as read or Mark all as read; each account sees its own updates. Android users can open My deliveries or the partner jobs screen. Handoff codes are sent separately by the admin.
