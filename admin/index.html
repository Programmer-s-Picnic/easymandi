How to use Easy Mandi admin

1. Update your catalog

  1. Review store settings, delivery fees and minimum order.
  2. Add a category before assigning products to it. Rename updates the products in that category. Move its products before deleting a category.
  3. Find or add a product. Enter a unique ID, name, category, unit and price. Enable Available to order when ready.
  4. Choose Validate catalog, then Save to server and enter the admin password. Changes become available when customers reload the catalog.

2. Manage customer orders

  1. Go to Customer orders, enter the admin password and choose Show orders.
  2. Filter by status, review items, totals, address and map pin.
  3. Choose a status and Update status. Refresh orders to see recent changes.
  4. Choose Open in delivery admin on an order to carry its ID into the import form. Sign in there and choose Import order.

3. Drafts and backups

Edits are saved as a draft in this browser. Save to server publishes them. Download backup saves a JSON copy without publishing.

Reload published catalog discards your draft after confirmation. If saving reports a changed server version, review the latest catalog before retrying.
