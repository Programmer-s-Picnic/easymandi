Start at New orders, work through payments and packing, then assign and track deliveries. The work queues show different views of the same saved orders: moving between queues does not create, duplicate, or delete an order.

Process a customer order

  1. Unlock the deskChoose Unlock operations and enter the admin password. Your secure session lasts 30 minutes; you can unlock again when it expires.पहले एडमिन लॉगिन करें।
  2. Receive and reviewOpen New orders. Select an order and check the customer's items, quantities, address, mobile, notes and total. Change the order status to Confirmed after reviewing it.
  3. Handle paymentFor UPI, open the submitted receipt, inspect its details and verify or reject it. For COD, mark payment paid only after money has actually been collected. Never mark an unpaid order as paid.
  4. Prepare and packUse Preparing / packing, check every item, and choose Print packing checklist. Print or save the checklist as a PDF. Add packing/delivery notes with the existing order tools if needed.
  5. Import and assign deliveryIn Awaiting assignment, choose Import for delivery if the order has no delivery record. Select an active delivery partner and choose Assign delivery partner. Assignment sends a handoff code to the customer through the established notification flow.
  6. Track the deliveryUse Active deliveries to see partner assignment, pickup and out-for-delivery states. The delivery partner completes the handoff with the customer's code/QR through the partner app. Use Advanced delivery management for resend-code and other specialist actions.
  7. Resolve and closeReview Exceptions for rejected receipts and long-unassigned orders. Use Completed to check finished or cancelled orders. Delivery completion should normally follow the partner's verified handoff, not a premature manual status change.

Daily routine

Morning: review pending UPI, new orders and old unassigned deliveries.
During the day: keep the queue open, confirm orders, pack, assign partners and follow exceptions.
Before closing: check incomplete deliveries, COD collections, receipts and finished orders.

Useful controls and safety

Search: enter order ID, name, mobile or locality (Ctrl+K focuses search). Refresh: the desk checks updates about every 30 seconds while visible; use Refresh anytime. Dates: shown in IST. Privacy: lock the admin on a shared computer. Fallback: legacy order and delivery administration remain available below.

Queue counts cover the stored records; each queue displays paginated results. Actions require an authenticated administrator and can be subject to server-side payment and delivery rules. No report here authorizes giving the delivery code before handing over the goods.

How to use Easy Mandi admin

1. Update your catalog

  1. Review store settings, delivery fees and minimum order.
  2. Add a category before assigning products to it. Rename updates the products in that category. Move its products before deleting a category.
  3. Search, filter or sort the product grid. Choose Add product, Update or Delete to open the record form. Insert and Update validate the fields before changing your draft.
  4. Choose Validate catalog, then Save to server. Sign in through the password pop-up if your 30-minute session has ended. Changes become available when customers reload the catalog.

2. Manage customer orders

  1. Sign in using the password pop-up, then go to Customer orders.
  2. Filter by status, review items, totals, address and map pin.
  3. Choose a status and Update status. Refresh orders to see recent changes.
  4. Choose Open in delivery admin on an order to carry its ID into the import form. Sign in there and choose Import order.

3. Drafts and backups

Edits are saved as a draft in this browser. Save to server publishes them. Download backup saves a JSON copy without publishing.

Reload published catalog discards your draft after confirmation. If saving reports a changed server version, review the latest catalog before retrying.

Choose Lock after reviewing orders on a shared device.

Use All records to inspect customer profiles, saved addresses, complete paginated order/payment history and delivery-partner records. Administrators only.

Notifications: While signed in, updates refresh every five minutes. New updates appear automatically without clicking Refresh or re-entering a password. Unread entries are highlighted. Use Mark as read or Mark all as read; each account sees its own updates. Android users can open My deliveries or the partner jobs screen. Handoff codes are sent separately by the admin.

Easy Mandi · Staff working guide

Each page uses the same server-side data and 30-minute administrator session. Do not use the Back button to repeat submissions. Refresh the relevant queue or records after a change.

1 · Operations Desk

  1. Open Operations Desk and unlock with the administrator password.
  2. Review the New orders queue, quantities, address, contact details and totals before confirming.
  3. Review UPI evidence or collect cash on delivery. Mark payment paid only after actual verification or collection.
  4. Prepare items, print a packing checklist, then import for delivery if needed.
  5. Assign an active partner, track progress, and check exceptions before closing the day.

2 · Products Master

  1. Open Products Master and review Store settings.
  2. Add categories before products. Update product details, price, stock availability and images in the catalog grid.
  3. Insert, Update and Delete edit a local draft, not the live catalog.
  4. Choose Validate catalog, then Save to server to publish.
  5. Use Download backup before important bulk changes. Reload published catalog only when it is safe to discard unsaved edits.

3 · Customers Master

  1. Open Customers Master and unlock private records.
  2. Search by customer name or mobile number.
  3. Open row details to inspect saved addresses and historical orders where available.
  4. Use Operations Desk for any order processing or customer delivery follow-up.
  5. Customer profiles are read-only in this initial release; do not expect edit or delete controls.

4 · Delivery Partners Master

  1. Open Delivery Partners Master and check registered partners, active status and jobs.
  2. Search or view details here; private records are read-only.
  3. For creating/editing partners, photographs, credentials or changing assignments, open Delivery administration ↗.
  4. Use the Operations Desk to track current customer-order dispatches and resend handoff details through existing delivery tools.

Session and privacy

An administrator session expires after 30 minutes. Sign in again when prompted. Avoid sharing screenshots of customer mobile numbers, addresses or handoff codes. Lock order records after working on a shared computer.

Useful troubleshooting

If an order appears missing, clear search or filters and use All orders or the paginated record explorer. If a catalog change does not appear for customers, ensure Save to server succeeded. If partner actions are unavailable here, use Delivery administration.
